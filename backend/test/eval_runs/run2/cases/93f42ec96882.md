## Query

Consider Inaturals's Non-Disclosure Agreement; Does the document specify whether the Receiving Party is required to destroy or return Confidential Information upon the termination of the Agreement?

## Gold

7. Upon written request from the other party, each party agrees to return or destroy all the other party’s Confidential Information, together with all copies or reproductions thereof.

## RAG Answer

No. Based on the provided document, the NDA does not expressly state that the Receiving Party must destroy or return Confidential Information upon termination of the Agreement.

It does provide return/destruction obligations, but only “upon request” or “upon written request”:

- Upon request, each party shall promptly return documents or tangible property containing Confidential Information, or destroy Confidential Information in tangible form.
- Upon written request, each party agrees to return or destroy all Confidential Information, including copies.

The confidentiality obligations are stated to last for three years following disclosure, but no automatic return/destruction requirement tied specifically to termination is specified in the provided text.
