## Query

Consider the Data Use Agreement in New York City; Does the document permit the Receiving Party to create a copy of some Confidential Information under certain circumstances?

## Gold

Except as set forth in Section III, Data Recipient shall not reproduce the Data in any form without the prior written consent of DOHMH.

## RAG Answer

Yes, but only in a limited way. In the provided Data Use Agreement, the receiving party is the **Data Recipient**. The document generally prohibits the Data Recipient from reproducing the Data/confidential information:

> “Except as set forth in Section III, Data Recipient shall not reproduce the Data in any form without the prior written consent of DOHMH.”

So the document permits creating a copy only if:

1. **Section III expressly allows it**, or  
2. **DOHMH gives prior written consent**.

Otherwise, the Data Recipient may not create copies of the Data.
