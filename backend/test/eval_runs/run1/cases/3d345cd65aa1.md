## Query

Consider the Data Use Agreement in New York City; Does the document allow the Receiving Party to share some Confidential Information with their employees?

## Gold

1. Only the Data Recipient’s employees and/or consultants required to use the Data to perform the functions of this Agreement that are set forth in Attachment B, and so designated by Data Recipient as “Authorized Users” in Attachment C to this Agreement, will be given access to the Data.

## RAG Answer

Yes. Under the Data Use Agreement, the Data Recipient may share access to the confidential Data with its employees, but only in a limited way.

Employees may access the Data only if they are designated as “Authorized Users” in Attachment C, are required to use the Data to perform the approved functions described in Attachment B, have been trained on the confidential nature of the Data, and have signed an Authorized User Agreement approved by DOHMH. The Data Recipient must also provide DOHMH with copies of the Authorized User Agreements before granting access and notify DOHMH of changes to the Authorized User list.

The document generally prohibits sharing the Data with any other person or organization except as permitted for Authorized Users.
